# ● REC

**REC** convierte tus cuestionarios en un concurso de televisión en directo. Cada acierto vale más cuanto antes se responde, el alumnado recibe un resguardo con un código de verificación y tú obtienes ranking, bonificaciones y un análisis detallado de lo aprendido. Funciona en cualquier móvil u ordenador, sin cuentas ni servidores: todo se publica gratis en GitHub Pages.

**REC** turns your quizzes into a live TV game show. The sooner students answer, the more each correct answer is worth; they get a ticket with a verification code, and you get rankings, bonuses and a detailed analysis of what they learnt. It works on any phone or computer, with no accounts or servers: everything is published for free on GitHub Pages.
